# Журнал технических решений

## TDR-001: Единое приложение backend + embedded frontend
- **Статус:** принято
- **Причина:** упрощение поставки и эксплуатации
- **Следствие:** frontend собирается в статику и кладется в ресурсы backend

## TDR-002: Storage SPI с переключением реализации по конфигурации
- **Статус:** принято
- **Причина:** поддержка file/h2/postgres без изменения доменного слоя
- **Следствие:** реализации выбираются через Micronaut `@Requires`

## TDR-003: Service selection как часть ядра, а не каналов
- **Статус:** принято
- **Причина:** единая бизнес-логика для всех каналов
- **Следствие:** каналы только адаптируют ввод/вывод
